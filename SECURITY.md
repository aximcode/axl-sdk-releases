# Security Policy

## Reporting a Vulnerability

Please do not file security issues on the public tracker.

Email **support@aximcode.com** with a description of the issue, steps
to reproduce, and the affected version or commit. Mark the subject line
with `[SECURITY]`. You will receive an acknowledgement within a few
business days.

## Supported Versions

AXL is under active development. Security fixes are applied to the
current `main` branch and the most recent tagged release. Older
releases are not maintained.

## General Questions

For non-security questions, please use GitHub issues on
[aximcode/axl-sdk-releases](https://github.com/aximcode/axl-sdk-releases)
or email **support@aximcode.com**.
