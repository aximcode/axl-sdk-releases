## The release procedure (per RELEASING.md)

Run **in this order**:

1. **Pre-tag gates (all must be green BEFORE bumping/tagging):**
   - Unit suites both arches: `timeout 200s ./test/integration/test-axl.sh
     --arch X64` and `--arch AARCH64` → `Results: 4767 passed, 0 failed`.
   - Other integration suites: `test-tools.sh`, `test-tcp-echo.sh`,
     `test-http.sh`, `test-cpu-idle.sh`.
   - RELEASE build both arches with a SEPARATE prefix (so RELEASE `.o`
     don't shadow the DEBUG cache):
     `make ARCH=x64 BUILD=RELEASE PREFIX=out/native-x64-release` and
     `ARCH=aa64 …PREFIX=out/native-aa64-release`.
   - TLS build (release.yml hardcodes `AXL_TLS=1`):
     `AXL_TLS=1 make ARCH=x64 BUILD=RELEASE PREFIX=out/native-x64-release`.
   - **FULL clang-tidy sweep** (CI uses `WarningsAsErrors:'*'`; this has
     been the post-tag failure mode TWICE): `rm -f compile_commands.json;
     bear -- make tests tools; find src -name '*.c' -not -path '*/backend/*'
     -not -name 'axl-mbedtls-platform.c' -print0 | xargs -0 -n1
     -P"$(nproc)" clang-tidy -p . -quiet; echo exit=$?` — must be 0.
     **One file per process (`-n1`)** — batched clang-tidy is flaky on
     `security.ArrayBound`.
   - `./scripts/build-docs.sh` clean.
2. **Bump:** `scripts/bump-version.sh 0.22.0` (updates `VERSION` +
   `include/axl/axl-version.h` together — NEVER edit by hand; Makefile
   `check-version` fails on mismatch).
3. **CHANGELOG:** write a new `## 0.22.0 — <date>` section at the top,
   swept from `git log v0.21.0..HEAD --oneline` (see grouping above).
   Added / Changed / Fixed. Catch the negative result (blit_transform
   SIMD reverted) under a note, and the behavior-affecting opt-ins
   (gamma).
4. **Release-metadata commit:** `git add VERSION include/axl/axl-version.h
   CHANGELOG.md; git commit -m "release: v0.22.0"` (keep it small).
5. **Push main FIRST:** `git push origin main` (branch must contain the
   metadata commit before the tag points at it).
6. **Tag + push:** annotated `git tag -a v0.22.0 -m "…headline + bullets…";
   git push origin v0.22.0`.
7. **Watch** via `scripts/watch-release-runs.sh` (GraphQL — NEVER
   `gh run watch`, per [[feedback-use-graphql-for-release-watch]]). Three
   workflows fire: CI, Release (→ public `aximcode/axl-sdk-releases`
   .deb/.rpm/tarball), Docs (→ Cloudflare Pages). ~4–5 min total.
