# `lsacpi` L1–L4 Implementation Plan

> **STATUS: L1-L4 ALL COMPLETE 2026-08-28.** Shipped across 15 commits; see each phase heading for its commits.
>
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `lsacpi` — an ACPI table browser that also correlates SMBIOS Type 9, SMBIOS Type 41, the ACPI namespace and PCIe Slot Capabilities into one view and marks where they disagree.

**Architecture:** Three library additions plus a tool. `axl_pci_read_slot_caps()` decodes the PCIe Slot Capabilities/Status block (L1). A non-evaluating AML walker parses `Name()` declarations out of DSDT/SSDT byte streams, skipping everything it does not understand by trusting PkgLength (L2). `lsacpi` renders the table inventory with checksums, typed decode and automatic hexdump (L3), then joins the four sources (L4). The namespace supplies topology and device:function; **PCI config space supplies every bus number** — no AML is ever executed.

**Tech Stack:** C (AXL public API only in tests), `AxlAcpi`, `AxlPci`, `AxlSmbios`, `AxlHexdump`, `AxlArgs`. QEMU + OVMF for integration. `iasl` as the independent oracle.

**Spec:** `docs/superpowers/specs/2026-08-23-lsacpi-design.md` (revised 2026-08-28 against real firmware — read §5a, §5b, §8a and §11 before starting; they were rewritten and contradict the original draft).

## Global Constraints

- **No AML execution, ever.** A `Method` body is skipped by length, never entered. No `OperationRegion` access. A reviewer must be able to confirm this by grepping for the absence of an evaluation loop (spec §4a).
- **Public API uses standard C types only.** No UEFI types, no `<uefi/…>` includes in `include/axl/`. `make check-uefi-scope` holds this at zero.
- **Tests use public headers only** (`feedback_test_public_headers`).
- **Exact-string assertions for tool output**: `axl_strcmp(buf, "…") == 0`, never `axl_strstr` (CLAUDE.md bucket B).
- **No `test_check(true, …)` tautologies.** `make check-tautology` enforces it.
- **Confirm RED before implementing.** Every task states the expected failure text.
- **`ARCH=aa64 ./test/integration/test-axl.sh` SILENTLY RUNS X64.** The script takes `--arch AARCH64` and ignores the env var. **Always check the banner.**
- **Never use `TEST_APPS_ONLY=…` under `--expect-fail`** — the filtered run's count sits below the ratchet baseline, so the harness fails on the ratchet, not on the sabotage, giving a false "detected".
- Every public-header change needs the matching `src/*/README.md` prose update **in the same change**, and `./scripts/build-docs.sh` is a zero-warning gate.
- Gate before every commit: `./scripts/verify.sh`. It runs **no integration test** — run those separately.
- Naming: `axl_snake_case`, `AxlPascalCase`, `AXL_SCREAMING_CASE`. 4-space indent, K&R, multi-line function signatures even for one parameter.

- [ ] **Step 1: Add the struct and declaration**

```c
// ---------------------------------------------------------------------------
// PCIe Slot Capabilities
// ---------------------------------------------------------------------------

/// PCIe capability ID (PCI Express Capability Structure).
#define AXL_PCI_CAP_ID_EXPRESS  0x10

/**
 * @brief Decoded PCIe Slot Capabilities and Slot Status.
 *
 * Meaningful only on a Root Port or a Switch Downstream Port whose
 * PCI Express Capabilities register has Slot Implemented set. Every
 * other function -- endpoints included -- returns AXL_ERR rather than
 * a zeroed struct, because "no slot" and "a slot reading zero" are
 * different facts and a caller must be able to tell them apart.
 *
 * @a physical_slot_number is what the silicon was strapped or
 * programmed to report. @a presence_detect is the only field here that
 * is not a build-time assertion: it is the hardware's live answer to
 * whether something is in the slot right now.
 */
typedef struct {
    uint16_t  physical_slot_number;   ///< Slot Cap bits 31:19
    uint8_t   port_type;              ///< PCIe Caps reg bits 7:4 (0x4 root, 0x6 downstream)
    bool      hotplug_capable;        ///< Slot Cap bit 6
    bool      hotplug_surprise;       ///< Slot Cap bit 5
    bool      attention_button;       ///< Slot Cap bit 0
    bool      power_controller;       ///< Slot Cap bit 1
    bool      mrl_sensor;             ///< Slot Cap bit 2
    bool      electromech_interlock;  ///< Slot Cap bit 17
    bool      no_command_completed;   ///< Slot Cap bit 18
    uint8_t   power_limit_value;      ///< Slot Cap bits 14:7
    uint8_t   power_limit_scale;      ///< Slot Cap bits 16:15
    bool      presence_detect;        ///< Slot Status bit 5 -- LIVE hardware state
    bool      mrl_sensor_closed;      ///< Slot Status bit 6
    bool      interlock_engaged;      ///< Slot Status bit 8
} AxlPciSlotCaps;

/**
 * @brief Read the PCIe Slot Capabilities and Slot Status of @p addr.
 *
 * Walks the standard capability chain for the PCI Express capability,
 * checks the Device/Port Type is a Root Port (0x4) or Switch Downstream
 * Port (0x6), and requires Slot Implemented to be set. Any of those
 * failing returns AXL_ERR without touching @p out.
 *
 * @return AXL_OK on success; AXL_ERR if @p out is NULL, @p addr has no
 *     PCI Express capability, is not a root/downstream port, or has
 *     Slot Implemented clear.
 */
AXL_WARN_UNUSED int
axl_pci_read_slot_caps(
    AxlPciAddr        addr,   ///< target function
    AxlPciSlotCaps   *out     ///< [out] receives decoded slot capabilities
);
```

## Task 3: Implement the reader

**Interfaces:**

- [ ] **Step 1: Write the implementation**

Register layout inside the PCI Express capability structure, offsets relative to the capability's own offset:

| offset | register |
|---|---|
| `+0x02` | PCI Express Capabilities (16-bit): bits 7:4 Device/Port Type, **bit 8 Slot Implemented** |
| `+0x14` | Slot Capabilities (32-bit) |
| `+0x1A` | Slot Status (16-bit) |

```c
/* SPDX-License-Identifier: Apache-2.0 */
/* Copyright 2026 AximCode */

/** @file axl-pci-slot.c
    PCIe Slot Capabilities and Slot Status decode.

    Its own translation unit rather than part of axl-pci.c so that
    --gc-sections drops it from images that never ask about slots.
**/

#include <axl/axl-pci.h>
#include <axl/axl-macros.h>

/* Offsets within the PCI Express capability structure. */
#define EXPRESS_CAPS_REG    0x02   /* 16-bit */
#define SLOT_CAP_REG        0x14   /* 32-bit */
#define SLOT_STATUS_REG     0x1A   /* 16-bit */

/* PCI Express Capabilities register. */
#define PORT_TYPE_SHIFT     4
#define PORT_TYPE_MASK      0x0F
#define SLOT_IMPLEMENTED    (1u << 8)

/* Device/Port types that may implement a slot. */
#define PORT_TYPE_ROOT_PORT        0x4
#define PORT_TYPE_DOWNSTREAM_PORT  0x6

static int
find_express_cap(
    AxlPciAddr   addr,
    uint16_t    *out_off
)
{
    uint16_t off = 0;
    uint16_t id  = 0;

    while (axl_pci_read_slot_caps_cap_next(addr, off, &off, &id) == AXL_OK) {
        if (id == AXL_PCI_CAP_ID_EXPRESS) {
            *out_off = off;
            return AXL_OK;
        }
    }
    return AXL_ERR;
}

AXL_WARN_UNUSED int
axl_pci_read_slot_caps(
    AxlPciAddr       addr,
    AxlPciSlotCaps  *out
)
{
    uint16_t cap_off = 0;
    uint16_t express = 0;
    uint32_t slot_cap = 0;
    uint16_t slot_sta = 0;
    uint8_t  port_type;

    if (out == NULL) {
        return AXL_ERR;
    }
    if (find_express_cap(addr, &cap_off) != AXL_OK) {
        return AXL_ERR;
    }
    if (axl_pci_read_config_16(addr, (uint16_t)(cap_off + EXPRESS_CAPS_REG),
                               &express) != AXL_OK) {
        return AXL_ERR;
    }

    port_type = (uint8_t)((express >> PORT_TYPE_SHIFT) & PORT_TYPE_MASK);
    if (port_type != PORT_TYPE_ROOT_PORT &&
        port_type != PORT_TYPE_DOWNSTREAM_PORT) {
        return AXL_ERR;
    }
    if ((express & SLOT_IMPLEMENTED) == 0) {
        return AXL_ERR;
    }

    if (axl_pci_read_config_32(addr, (uint16_t)(cap_off + SLOT_CAP_REG),
                               &slot_cap) != AXL_OK) {
        return AXL_ERR;
    }
    if (axl_pci_read_config_16(addr, (uint16_t)(cap_off + SLOT_STATUS_REG),
                               &slot_sta) != AXL_OK) {
        return AXL_ERR;
    }

    out->port_type             = port_type;
    out->attention_button      = (slot_cap & (1u << 0))  != 0;
    out->power_controller      = (slot_cap & (1u << 1))  != 0;
    out->mrl_sensor            = (slot_cap & (1u << 2))  != 0;
    out->hotplug_surprise      = (slot_cap & (1u << 5))  != 0;
    out->hotplug_capable       = (slot_cap & (1u << 6))  != 0;
    out->power_limit_value     = (uint8_t)((slot_cap >> 7)  & 0xFF);
    out->power_limit_scale     = (uint8_t)((slot_cap >> 15) & 0x03);
    out->electromech_interlock = (slot_cap & (1u << 17)) != 0;
    out->no_command_completed  = (slot_cap & (1u << 18)) != 0;
    out->physical_slot_number  = (uint16_t)((slot_cap >> 19) & 0x1FFF);
    out->presence_detect       = (slot_sta & (1u << 5)) != 0;
    out->mrl_sensor_closed     = (slot_sta & (1u << 6)) == 0;
    out->interlock_engaged     = (slot_sta & (1u << 8)) != 0;
    return AXL_OK;
}
```

```c
// ---------------------------------------------------------------------------
// AML namespace walker -- parsing only, never evaluation
// ---------------------------------------------------------------------------

/// Maximum namespace path captured, e.g. "\_SB.PC00.RP05.PXSX".
#define AXL_AML_PATH_MAX  128

/// Nesting depth cap. Firmware is untrusted input; a malformed table
/// must produce a bounded walk, not a runaway.
#define AXL_AML_DEPTH_MAX  32

/**
 * @brief How a named object's value was obtained -- or why it wasn't.
 *
 * The distinction is the whole point: a static walker CAN read
 * Name(_ADR, 0x001C0004) and CANNOT read Method(_ADR){...}, and a
 * consumer must never confuse the second with "absent". Measured on
 * real firmware, 34% of _ADR and 85% of _PLD are Methods.
 */
typedef enum {
    AXL_AML_VALUE_STATIC = 0,   ///< a literal in the byte stream; @a value is valid
    AXL_AML_VALUE_METHOD,       ///< declared as a Method; present but unreadable
    AXL_AML_VALUE_ABSENT        ///< not declared at all
} AxlAmlValueKind;

/**
 * @brief One device found in the namespace.
 */
typedef struct {
    char             path[AXL_AML_PATH_MAX];  ///< full path, NUL-terminated
    bool             conditional;             ///< declared inside an If -- may not exist at runtime
    AxlAmlValueKind  adr_kind;
    uint64_t         adr;                     ///< valid only when adr_kind == STATIC
    AxlAmlValueKind  sun_kind;
    uint64_t         sun;                     ///< valid only when sun_kind == STATIC
    AxlAmlValueKind  uid_kind;
    uint64_t         uid;                     ///< valid only when uid_kind == STATIC
    AxlAmlValueKind  seg_kind;
    uint64_t         seg;                     ///< valid only when seg_kind == STATIC
    AxlAmlValueKind  bbn_kind;
    uint64_t         bbn;                     ///< valid only when bbn_kind == STATIC
    AxlAmlValueKind  pld_kind;                ///< value itself is a buffer; not decoded here
} AxlAmlNode;

/// Opaque walk state. Allocate on the stack; no heap, no ownership.
typedef struct AxlAmlWalk AxlAmlWalk;

/**
 * @brief Begin walking the AML in @p table.
 *
 * @p table is a DSDT or SSDT header. The walk is read-only and
 * allocates nothing. Call axl_aml_walk_next until it returns false.
 *
 * @return AXL_OK on success, AXL_ERR if @p table or @p walk is NULL or
 *     the table is too short to contain a definition block.
 */
int
axl_aml_walk_begin(
    AxlAmlWalk           *walk,   ///< [out] caller-allocated walk state
    const AxlAcpiHeader  *table   ///< DSDT or SSDT
);

/**
 * @brief Yield the next Device found.
 *
 * Devices are yielded in declaration order. A Device inside an If
 * body is yielded with @a conditional set -- the walker cannot know
 * whether the condition holds without evaluating AML, so it reports
 * the device and the doubt rather than guessing (spec §5b).
 *
 * @return true when @p out was populated; false at end of table or on
 *     a malformed structure that stops the walk.
 */
bool
axl_aml_walk_next(
    AxlAmlWalk   *walk,   ///< walk state
    AxlAmlNode   *out     ///< [out] receives the device
);

/**
 * @brief Report whether the walk stopped early on malformed AML.
 *
 * A bounded stop is correct behaviour, not a crash -- but a consumer
 * rendering a device list must be able to say "the table was truncated
 * here" instead of implying it saw everything.
 *
 * @return true if the walk ended because the byte stream was
 *     malformed; false if it reached the end of the table cleanly.
 */
bool
axl_aml_walk_truncated(
    const AxlAmlWalk  *walk
);
```

`struct AxlAmlWalk` is defined in the header (not opaque in the C sense) so callers can stack-allocate; keep its members undocumented and prefixed to signal they are private.
